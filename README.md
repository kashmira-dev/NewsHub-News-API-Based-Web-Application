# NewsPulse – News API Based Web Application

## 📖 Project Description
NewsPulse is a web-based news application developed using HTML, CSS, JavaScript, and Node.js (Express).
This application fetches real-time news data from the NewsAPI and displays news articles based on user-selected search criteria.

Users can search news articles using:
- Keywords or phrases
- Date published
- Source domain
- Language

The goal of this project is to demonstrate how to integrate an external API with a backend server and display data using a clean and user-friendly frontend interface.

---

## 🛠 Technologies Used
### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### API
- NewsAPI (https://newsapi.org)

---

## ⚙️ Features
- Search news by keyword
- Filter news by date
- Select language
- Display news headlines, descriptions, and article links
- Responsive and attractive user interface
